# Changelog

## 0.2.0 - 2026-08-06

### Added

- Refined responsive desktop and Android user interface
- Encrypted member avatars
- Declarative JSON server mods and permission-limited slash commands
- Join-only Android client with Android Keystore vault protection
- Android APK build, emulator launch smoke test, and release artifact


## 0.1.0 - 2026-08-05

### Added

- Self-hosted Electron desktop server and client
- Temporary and permanent invitation codes
- Explicit administrator device approval
- Ed25519 device authentication
- X25519 sealed room-key delivery
- XChaCha20-Poly1305 message, file, sticker, and background encryption
- Pinned self-signed TLS for HTTPS and WSS
- Role-based custom permissions
- Encrypted file transfer up to 25 MiB
- Built-in and custom stickers
- Server background management
- Audit records and optional debug logs
- OS-protected client vault through Electron safeStorage
- Cross-platform packaging workflows
- CodeQL, production dependency audit, integration tests, and documentation
- Verified unpacked desktop packaging on Windows, macOS, and Linux before the initial merge
